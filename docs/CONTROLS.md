# Pokémon Snap 3DS — controls

| 3DS | N64 | In Pokémon Snap |
|---|---|---|
| Circle Pad | Control Stick | aim the camera / move the cursor |
| A | A | take a picture (while zoomed) / throw an apple / OK |
| B | B | throw a Pester Ball / back |
| L, ZL, ZR | Z | zoom (hold) |
| R | R | Dash Engine |
| Y | C-Down | Poké Flute |
| X | C-Up | |
| C-Stick (New 3DS) | C buttons | |
| Start (or Select) | Start | pause |
| Start + Select | — | quit to the HOME menu |

Mapping: source/port/input_3ds.cpp. Taking a picture needs zoom: hold L (or ZL/ZR), press A.
